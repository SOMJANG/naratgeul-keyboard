# 나랏글 키보드

피처폰 시절 쓰던 **나랏글 자판**을 iPhone 에서 그대로 쓰는 키보드입니다.
자음 여섯 개(ㄱ ㄴ ㄹ ㅁ ㅅ ㅇ)와 모음 네 개에 **획**·**쌍** 키를 더해 한글 전체를 칩니다.

스마트폰 한글자판 국가표준(2011년 제정, 천지인·나랏글·SKY 복수표준) 가운데 나랏글 방식을 구현했습니다.

## 쓰는 법

1. **설정** ▸ **일반** ▸ **키보드** ▸ **키보드** ▸ **새로운 키보드 추가**
2. 목록에서 **나랏글** 선택
3. 키보드에서 🌐 를 눌러 나랏글로 전환

앱을 열면 **연습 모드**가 있습니다. 자음 자리부터 문장까지 일곱 단계로 나눠 두었고,
막히면 "누르는 순서 보기"로 힌트를 볼 수 있습니다.

## 입력 규칙

```
획      ㄱ ↔ ㅋ          ㄴ → ㄷ → ㅌ → ㄴ
        ㅁ → ㅂ → ㅍ → ㅁ   ㅅ → ㅈ → ㅊ → ㅅ
        ㅇ ↔ ㅎ
쌍      ㄱ ↔ ㄲ   ㄷ ↔ ㄸ   ㅂ ↔ ㅃ   ㅅ ↔ ㅆ   ㅈ ↔ ㅉ
모음    ㅏㅓ · ㅗㅜ 키는 거듭 누르면 뒤 글자, 획을 더하면 ㅑㅕㅛㅠ
```

획과 쌍은 **방금 친 자음**에 걸립니다. 받침으로 들어간 자음도 마찬가지입니다.
